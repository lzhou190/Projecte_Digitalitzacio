# Descripción Asistente de menú saludable
Este proyecto es un aplicación web interactiva que utiliza la inteligencia artificial, para analizar diferentes platos y menús a aprtir de fotografías subidas por el usuario. Su objetico principal es evaluar si la comida es saludable, ofrecer un análisis detallado y proponer las mejores combinaciones o mejorar para una alimentación equilibrada.
Todo con el funcionamiento está desarollado con el código Python y se visualiza y ejecuta mediante la herramienta Streamlit.
